# 푸끼먼 — 포켓몬 한국어 통합 도감

포켓몬 정보를 찾아볼 수 있도록 제작한 개인용 한국어 통합 도감입니다. iPad에서 웹 앱처럼 사용하고, 네트워크 연결이 없는 환경에서도 열람할 수 있도록 구성한 프로젝트입니다.

## 구성 및 동작 원리

이 저장소에는 웹 앱의 핵심 파일이 포함되어 있습니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 도감의 웹 페이지와 앱 콘텐츠 |
| `manifest.webmanifest` | 앱 이름, 아이콘, 홈 화면 실행 형태 등의 설정 |
| `sw.js` | Service Worker: 주요 파일을 브라우저 캐시에 저장하고 오프라인 요청에 재사용 |
| `icon-192.png`, `icon-512.png` | 홈 화면 및 앱 아이콘 |

이러한 형태를 **PWA(Progressive Web App)** 라고 합니다. 일반 웹사이트를 iPad 홈 화면에 추가해 앱처럼 실행하도록 설계할 수 있습니다.

## 사용 방법

1. 이 저장소의 웹 페이지를 **HTTPS로 제공되는 주소**에서 Safari로 엽니다. (이 저장소에 포함된 파일만으로 실제 배포 URL을 확정할 수는 없습니다.)
2. Safari 공유 메뉴에서 **홈 화면에 추가**를 선택합니다.
3. 앱이 온라인 상태에서 처음 로드되고 Service Worker가 주요 파일을 캐시한 뒤에는, 캐시된 콘텐츠를 오프라인에서도 열 수 있도록 설계되어 있습니다.

> 주의: Service Worker는 일반적인 GitHub 소스코드 보기 화면이나 로컬 `file://` 열기 방식에서 정상적으로 작동하지 않습니다. 온라인 첫 로드와 캐시 설치가 필요하며, 실제 iPad 오프라인 동작은 기기에서 검증해야 합니다.

## 유지 관리

- 도감의 내용을 변경할 때는 주로 `index.html`을 수정합니다.
- 배포 후 오프라인에서 이전 내용이 계속 보인다면 Service Worker 캐시 버전(`sw.js`의 `CACHE` 값)을 갱신해야 할 수 있습니다.
- 데이터 내용과 기준 버전, 배포 URL은 추후 검증하여 문서화할 수 있습니다.
